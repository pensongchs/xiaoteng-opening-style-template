# 小滕片头风格模板

使用简体中文。交付能用于剪辑的片头 MP4、关键帧及工程；用户仅要求规划或修改文案时停在对应范围。

## 环境与母工程

技能安装目录记为 `SKILL_ROOT`，实际制作目录记为 `PROJECT_ROOT`；从本文件位置与用户工作目录推导，不复制开发者路径，不要求学员手动改脚本。首次准备按 [references/运行与复刻.md](references/运行与复刻.md) 执行。

- 优先续接工作目录中已经创建的片头母工程。没有时，通过 `node "SKILL_ROOT/scripts/create-project.mjs" "PROJECT_ROOT"` 将 `assets/workspace/` 复制到用户工作目录的 `outputs/片头制作专用/`。别在技能安装目录制作、渲染或写缓存。
- 先运行 `node scripts/doctor.cjs`；准备运行环境时执行 `node scripts/setup.cjs`，脚本自动识别系统、版本、芯片、Node、内存与并发数。没有 Node 时用 `start.command` 或 `start.cmd` 显示匹配的官方下载入口，再由当前 Codex 完成安装与复查。
- 相同的依赖清单、锁文件、包管理器、Node 主版本、系统和架构共用运行组；Windows 使用目录联接，Mac 使用目录链接。禁止对共享 `node_modules` 原地装包。依赖变动先更新清单与锁文件，再执行 setup。
- 准备会联网下载 npm 包、官方背景和渲染浏览器，统一缓存到用户 Codex 目录。用户已授权安装或准备环境时直接完成，不重复确认；涉及系统软件安装、升级或额外付费时按当前授权处理。
- 字体已随包提供，只校验并在网页内加载，不安装到系统。背景由 setup 从官方固定提交获取并适配视频帧，勿把受限制的第三方背景源文件再次打包发布。
- 环境检查通过后执行 `npm run check`；新电脑必须完整渲染随包示例并运行 `npm run verify`，不能用“目录已创建”代替可用性验证。

## 单期制作

读取工作母工程中的 `DESIGN.md`，按需要查看 `src/Opening.tsx`、`src/openingConfig.ts`、`src/Root.tsx`。当前随包示例为“2027年买房，真正的分水岭，不是新房和二手房”，用于复现风格及验证，不直接套用其住宅、年份或3.68秒时长。

1. 先核对文案、指定范围和真实 SRT/毫秒节点。没有时间码时可先规划；不要把估计节点说成真实口播同步。缺失的原声或时间码会明显影响准确制作时，只询问这一项，不索要已能定位的文件。
2. 在 `分镜规划/{期名}/{期名}_片头规划.md` 写明文案、原视频起止、帧率、帧数、剪辑起点、素材性质和语义节点表。只制作用户指定范围，默认16:9、1920×1080、50fps、纯画面，不加口播字幕与配音。
3. 优先用户素材；独立主体使用真实透明通道、自然照片质感。随包两张住宅是AI示意，可用于学习；制作其他主题时按本期含义更换。数字、条件与类别对比需有对应语义动作，分类在轮廓、材质和颜色上一眼可辨。
4. 每期复用 `Opening.tsx` 与 `openingConfig.ts`。示例中含有年份滚轮、固定短语和构图坐标，换主题时检查源码的实际读取与硬编码，不能只改配置就宣称已换片。同步调整资产路径、Root规格、节点与屏显；字体、背景、标题材质等公共实现保持复用。
5. 动画全部按 `useCurrentFrame()` 和 fps 驱动，帧数 `round((结束毫秒-开始毫秒)*fps/1000)`；减去片头起点后再换算相对节点。等待字体、素材与GPU完成，加载失败明确报错。

## 渲染、验证和交付

在工作母工程中运行：

```text
npm run check
npm run render -- "renders/期名_横屏片头.mp4"
npm run verify -- "renders/期名_横屏片头.mp4"
npm run still -- 0 "预览图/期名/01_首帧.png"
```

静帧帧号按当期实际节点选择，覆盖首尾、短语入场、换位中段与稳定落版。核对手机可读性、透明边缘、ID、安全区、亮部和主体层次；有问题修正受影响部分后重渲染。最终交付的规划、素材、预览、成片目录按 `DESIGN.md` 执行，同一期只维护当前有效版本。

媒体检查与视觉检查分开说明。未核听原声不说“音画同步通过”，内部检查不替代用户观看确认。用本地绝对路径内嵌成片并附链接；只有用户要求时打开播放器、浏览器、Studio或审片台。若仅演示环境已可用，应明确说明是随包示例。
